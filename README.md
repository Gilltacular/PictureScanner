Design Considerations & Framework Implementation
As has been found in studies such as the paper entitled The Role of Visual Complexity and Prototypicality Regarding First Impression of Websites: Working Towards Understanding Aesthetic Judgments, the less visual complexity a web page has, the more it is rated as highly appealing to users (Tuch, Presslaber, Stocklin, et al., 2012). It is with this in mind that the development team has decided the picture scanner project’s look and feel will be represented by a graphical user interface (GUI) which reflects a minimalist design. The tool will focus on a simple to use and intuitive feature set. This feature set will be extremely fast and convenient for the user and consistent across all environments.

We are using the BootStrap framework to dynamically change page content depending on the browser’s size. This application will ensure consistency and simplicity for our tool to be used by a variety of users from diverse fields and each with their own individual platform/environment needs. The bootstrap framework is an open source front-end framework for unifying website and web application design across devices. It utilizes Javascript, HTML, and CSS as well as various tools such as templated forms, buttons, and typography to enable developers to create responsive websites that can be viewed across multiple devices with ease. Bootstrap is a front-end framework, which means that is acts as an interface for the user; in contrast to server-side code, which usually is interfaced through a server or remote process of some sort.
The CSS being used in the Bootstrap framework is the heart of what allows it to adapt to different device’s display requirements and screen sizes. It is essentially a set of premade stylesheets and definitions that control all HTML components; giving enhanced functionality to text, tables, and forms and the ability to format them dynamically.

Javascript is utilized in Bootstrap to round out the CSS flexibility and give the framework an enhanced set of plugins bringing each their own powerful functionality. For example, the Javascript elements are typically in the form of jQuery plugins, which allow for the creation of many of the user interface objects.

Web Tool Design Layout Description
 
	The first page applicants will encounter will be the sign up screen. This landing page will give a brief one-line overview of the tool and provide the ability to sign up at the forefront of the project’s page. 
 
	If the user has already created an account, they will instead be directed to a sign-in page or the repo/tool page should they already be logged in. In this way, we best capture the intent of the user visiting the site and provide them with the picture scanning functionality they seek.
 
The repo, or tool page, is the area where users can utilize the web tool to search or upload images by various functions. For instance, if a user would like to search the existing database of images for images that are primarily red based they could easily select red and be returned with images that match such color criteria. If the user would like to add images to the repository of stored images for search, they can do so by selecting the upload option. The purpose for this page is to include the tool and all functionality needed within a single load of the page once the user has logged in. Elements of the search functionality will trigger content in other segments of the page to show customized results based on what the user would like to accomplish with their search criteria.
